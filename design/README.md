# Design sources

Source assets that are **not** served to the browser. Kept here so the
generated files in `src/app/` can be reproduced.

- `2m-logo.svg` — the 2M monogram. Source for `src/app/favicon.ico`
  (16/32/48px), `src/app/icon.png` (256px) and `src/app/apple-icon.png` (180px).
  The mark is drawn as stroked geometry, not text, so it renders identically
  without depending on any font being installed.
